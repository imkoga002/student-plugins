# 研究の誠実さの点検

講評言語(`.ryukoku/config.yml` の `feedback_lang`)が `en` のときは、学生への応答を英語で書く(この指示文は日本語のままでよい)。

## なぜこの形か
人文・社会科学では捏造・改ざんより盗用が特に多く、コピペがそれを容易にする(JSPS『科学の健全な発展のために』第2版 Ⅲ-5.3、https://www.jsps.go.jp/file/storage/j-kousei/data/rinri.pdf)。龍谷大学の研究不正の定義は捏造・改ざん・盗用に二重投稿と不適切なオーサーシップを加えた五類型である(龍谷大学「研究活動に係る不正行為の防止及び対応に関する規程」第2条(1)、https://www.kenkyubu.ryukoku.ac.jp/cms/wp-content/uploads/2025/07/9f6a9c168ad42361b5b6225d988e7ebd.pdf)。道具は重なりを示すだけで、盗用かどうかは判定しない。

## 重なりの点検(n-gram)
1. 学生に、読んだ資料から重なりを調べたい部分を `excerpts/<名前>.md` に写して保存してもらう(1 行目に `source_id: S001`)。抜粋は著作物なので既定で Git に入れない。
2. `python3 tools/rk/rk.py overlap --out review/overlap-report.md`
   - 日本語は空白を除いた文字 12-gram、英語はより長い単位で重なりを探す
   - 引用符(「」『』“”)かブロック引用で区別されているか、同じ段落に出典([@key]、[^n]、(著者 年))があるかを示す
3. 「要確認」の行を学生と一緒に見る。直すのは学生: 引用にするなら「」で区別して出典と頁を示す(著作権法32条・48条。明瞭区別性・主従関係は JSPS 第2版 Ⅳ-5.4.1)、言い換えるなら自分の言葉で書いて出典を示す。AI が言い換えの文を出さない。

## 五類型の点検(問いの形で)
- 捏造: 本文の数値・事実に、台帳とデータの裏づけがあるか(`./rk check`、`rk.py data numbers`)
- 改ざん: データの加工の記録があるか、都合のよい部分だけを使っていないか(`bias-check`)
- 盗用: 上の重なりの点検。アイデアや用語の借用も出典を示しているか
- 二重投稿: 他の科目に出したレポートの使い回しがないか(学生に尋ねる)
- 不適切なオーサーシップ: 共同研究なら分担を書いたか。AI を著者や代筆者にしていないか
人を対象とする調査(アンケート・インタビュー)は、倫理審査の要否を指導教員に確かめるよう勧める(学部の卒論が対象になるかは公開資料で確認できないので断定しない)。
