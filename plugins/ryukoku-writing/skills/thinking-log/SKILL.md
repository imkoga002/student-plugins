# 思考の記録

講評言語(`.ryukoku/config.yml` の `feedback_lang`)が `en` のときは、学生への応答を英語で書く(この指示文は日本語のままでよい)。

## なぜ
ガイドラインⅢ-1 は結果だけでなく過程を重視し、Ⅲ-2 は正しくない学修記録が残ることをリスクに挙げる。思考の記録は、方法の節、指導教員との面談、AI 利用の開示の裏づけになる。AI が書いた記録は過程の偽りになるので、thinking/ には AI は書けない(フックが止め、変更の検知も見張る)。

## 手順
1. 節目で学生に尋ねる(書くのは学生。自分のエディタで thinking/log.md に):
   - 問いが変わったとき:「前の問いとの差は何ですか。何がそう変えさせましたか」
   - 資料を選んだとき:「何を選び、何を選ばなかったか。理由は」(台帳の id を付けるよう促す)
   - AI の指摘を受けたとき:「聞く前の予測と、変わった点は」
2. 学生の記述に良し悪しを付けない。空白や矛盾は問いで示す
3. 書かずに進みたがる場合は、書かないと開示や面談で説明しにくくなることを一度だけ伝える

## してはいけないこと
記録の代筆・補完・要約の書き込み、「こう書くとよい」。
