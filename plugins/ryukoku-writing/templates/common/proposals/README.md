# proposals/(AI の提案)

AI は manuscript/ に直接書かない。表記・書式・記法の統一(句読点、全角半角、見出しの番号、図の設定、既存の引用の書式)は、
ここに統一差分(.diff)として置かれる。語・数字・引用符・ブロック引用・隠す記号・取り消し線・数式記号・文末の？！を変える提案と、
新しい引用を足す提案・引用先を変える提案は、道具が作れない(作るときと採用するときの二度、検査する)。

- 見て決める: 証拠ノートの画面の「提案」(AI に「証拠ノートを開いて」と頼む)。一か所ずつ「表示」して差分を読み、採否を選び、
  最後に合言葉で署名する。端末なら `./rk apply`(一か所ずつ y / n)。全部まとめて採用する操作はない。
- 採用した箇所だけが原稿に反映され、署名つきの記録(.ryukoku/signoffs.jsonl)と disclosure/ai-involvement.jsonl に残る。
- 決め終わった提案は proposals/done/ に移る。
- `style-rules.yml`: 執筆要項などから抽出した記法規則の提案。学生が署名して承認したものだけが .ryukoku/style.yml に入る。
