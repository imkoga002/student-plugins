# disclosure/(AI 利用の開示の材料)

AI はこのフォルダに書けない。

- `ai-involvement.jsonl`: 学生が採用した AI の提案(どのファイルの、どの表記・書式の統一か)。署名と同時に自動で追記される。
- `./rk facts` で、ガイドラインⅢ-4 の記載項目の例(AI の種類・バージョン、利用年月日、プロンプトの概要、どの部分でどのように)
  に沿った事実の一覧が出る。プロンプトの概要は、学生が日ごとに自分の言葉で書いて署名したもの(画面の「提出前」か `./rk disclose`)。
- 開示文は自分で書く(このフォルダに置いてよい)。形式と置き場所は科目の指示に従う。
