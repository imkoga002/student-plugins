# disclosure/(AI 利用の開示)

- `statement.md`(`statement` で始まる .md): 開示文。AI が `./rk facts` の事実から下書きしてよい(disclosure スキル)。
  提出前の最終確認(合言葉の署名)は、このファイルの内容に結びつく。署名の後に変えると最終確認がやり直しになる。
- `ai-involvement.jsonl`: 学生が採用した AI の提案(どのファイルの、どの表記・書式の統一か)。採用と同時に自動で追記される。AI は書けない。
- `./rk facts` で、ガイドラインⅢ-4 の記載項目の例(AI の種類・バージョン、利用年月日、プロンプトの概要、どの部分でどのように)
  に沿った事実の一覧が出る。どの段落を AI が書いた・直したかは `.ryukoku/provenance.jsonl`(由来の記録)から出る。
  学生の編集は、AI のツール実行の間の差分からの推定である。プロンプトの概要は、学生が日ごとに自分の言葉で書いたもの(画面の「提出前」か `./rk disclose`)。
- 形式と置き場所は科目の指示に従い、担当教員に確かめる。
