# claims/(主張カード)

一枚に一つの主張。考え・直感・ニッチな着眼を AI に話すと、AI が問いかけながら `C001.md` のようなカードに整理する
(idea-intake スキル。`python3 tools/rk/rk.py claims new --words "<自分の言葉>"`)。

- 節: 主張 / 範囲と限定 / 必要な根拠 / 論拠 / 予想される反論 / 新規性の見込み / 学生の言葉の原文
- 「学生の言葉の原文」は、あなたが言ったことをそのまま残す節。AI の言い換えと分けるため。
- AI が足した候補(論拠・反論など)は、行頭に `[ai_suggested]` が付く。確認の対象には入らない。
- `status: draft` のカードは、あなたが確認するまで執筆の材料にならない。確認は証拠ノートの「主張カード」のボタンか `./rk confirm`
  (合言葉は要らない)。AI は確認を付けられない(ファイルに confirmed と書いても、記録がなければ `./rk check` が落ちる)。
- 確認の後に主張・範囲・自分の言葉を変えると、確認はやり直しになる。
