# .ryukoku/(設定と、人間の判断の記録)

AI はこのフォルダに書けない(Plugin のフックがすべての道具で止め、ツール実行中の変更も検知する)。

- `config.yml`: プロジェクトの目印と設定。科目の AI 利用条件は `./rk setup` で書いて署名する。
- `signers.json`: 署名者の公開鍵だけ。合言葉と秘密鍵はどこにも保存しない(使うたびに合言葉から作り、使い終わったら捨てる)。
  GitHub を使うときは、main に commit された版が信頼の起点になる(PR の中の署名者は信頼しない)。
- `signoffs.jsonl`: 学生が合言葉で署名した判断(VERIFIED、提案の採否、規則の承認、コメントの解決、節の署名、提出前の確認、
  日ごとの AI 利用の概要、検知した変更の判断、オプトアウト、科目条件)。各行は判断した内容のハッシュと Ed25519 の署名を持つ。
- `ai-use-log.jsonl`: フックが自動で書く AI 利用の記録。プロンプトの本文は書かない(種類だけ)。各行が前の行のハッシュを持ち、
  行を消すと `./rk check` と CI が落ちる。
- `style.yml`: 学生が署名して承認した記法規則だけ。
- `cache/`: API の応答の一時置き場(Git に入れない。J-STAGE の規約は 24 時間を超える保存を禁じている)。
