# .ryukoku/(設定と、人間の判断の記録)

AI はこのフォルダに書けない(Plugin のフックがすべての道具で止め、ツール実行中の変更も検知する)。ここにあるのは、記録の正しさを支えるものだけ。

- `config.yml`: プロジェクトの目印と設定。科目の AI 利用条件(allowed / limited / prohibited / unknown)と根拠は `./rk setup` で書いて確認する。AI が原稿を書いてよいかは、この条件で決まる。
- `signers.json`: 署名者の公開鍵だけ。合言葉と秘密鍵はどこにも保存しない(使うたびに合言葉から作り、使い終わったら捨てる)。
  GitHub を使うときは、main に commit された版が信頼の起点になる(PR の中の署名者は信頼しない)。
- `signoffs.jsonl`: 学生の判断の記録。VERIFIED と提出前の最終確認は合言葉の Ed25519 署名つき。ほかの判断(主張カードの確認、
  提案の採否、規則の承認、コメントの解決、節を読んだ確認、日ごとの AI 利用の概要、検知した変更の判断、オプトアウト、科目条件)は
  署名のない確認で、判断した内容のハッシュに結びつく。
- `provenance.jsonl`: 原稿の段落ごとの由来(AI が書いた・直した、学生が書いた・直した(推定)、材料の主張カードと文献)。
  フックと道具が自動で追記し、各行が前の行のハッシュを持つ。開示の事実(`./rk facts`)になる。
- `ai-use-log.jsonl`: フックが自動で書く AI 利用の記録。プロンプトの本文は書かない(種類だけ)。各行が前の行のハッシュを持ち、
  行を消すと `./rk check` と CI が落ちる。
- `style.yml`: 学生が承認した記法規則だけ。
- `cache/`: API の応答の一時置き場(Git に入れない。J-STAGE の規約は 24 時間を超える保存を禁じている)。
