# バイアスの点検(ガイドラインⅡ-2(2): ハルシネーションとバイアス。学生が使うチェックリスト)

答えは自分で書く。AI はこの表の観点で「問い」を出すだけ。

| 観点 | 問い | 自分の答え・対応 |
|---|---|---|
| 事例の選び方 | 結果が出た事例だけを選んでいないか。結果が出なかった事例では同じ要因はどうか(Geddes 1990: 従属変数での事例選択) | |
| 根拠の選び方 | 自分の結論に反するデータや先行研究を探したか(G5 根拠の選択的使用) | |
| 自己選択 | アンケート等の回答者が自分で参加を選んだ集団ではないか | |
| 資料の立場 | 資料の作り手(政府・企業・団体・研究者)の立場や利害は何か。同じ立場の資料だけに頼っていないか | |
| 言語・地域 | 日本語(または英語)の資料だけで判断していないか | |
| 期間 | 都合のよい年だけを切り出していないか。前後の年ではどうか | |
| AI の出力 | AI が出した要約・候補を、複数の信頼できる情報源で確かめたか(Ⅱ-2(2))。AI が挙げなかった資料を自分で探したか | |
| 用語 | 評価語(「遅れている」「優れている」など)の基準を示したか(D3) | |
