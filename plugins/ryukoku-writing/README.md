# ryukoku-writing の使い方

レポートや卒業論文を、AI(Claude)と一緒に書くための追加機能です。パソコンに詳しくなくても使えるように、この説明では専門の言葉をできるだけ使わずに書いています。

> **いまは作り直しの途中です。** この説明は、作り直した後の使い方(版 3.0)を先に書いたものです。まだ準備中の部分があり、この手順どおりに最後まで進められるとは限りません。どこまで使えるかは、最後の「いま使えるところ・準備中のところ」の表を見てください。

> **龍谷大学の公式の道具ではありません。** 授業の先生、学部、大学の指示が、いつもこの道具より優先します。迷ったら先生に聞いてください。

## これは何をしてくれるのか

あなたが考えたことを、AI が聞き取って整理し、論文の形にするのを手伝います。手伝いの中身は次の四つです。

- **考えの整理**: 思いついたことをチャットで話すと、AI が「主張カード」(あなたの言いたいことを一枚ずつまとめたメモ)に整理します。あなたが話した言葉は、そのまま残ります。
- **資料探し**: 本や論文を探し、本当にある資料かどうかを確かめます。AI がうろ覚えで資料をでっち上げることはしません。
- **点検**: あなたの主張と文章に、筋の通らないところや根拠の足りないところがないかを、厳しく点検します。
- **文章を書く手伝い**: 授業で AI を使って文章を書くことが許されているときだけ、下書きを手伝います。

AI が書いた文は、どこを書いたかが自動で記録されます。提出のときに「どこで AI を使ったか」を正直に書けるようにするためです。

## 先に知っておいてほしいこと

- **AI をどこまで使ってよいかは、授業ごとに違います。** シラバス(授業の説明の資料)や、先生の話を確かめてください。この道具は、あなたが決めた条件に合わせて動きます。
- **問いと主張は、あなたのものです。** 「何を調べるか」「何を言いたいか」を、AI が代わりに決めることはありません。一緒に考えることはします。
- **名前・学籍番号・住所・電話番号・メールアドレスなどは、チャットに書かないでください。** 電話番号・メールアドレス・住所などの多くは、送る前に止まります。ただし名前は見分けられず、書き方によっては止まらないこともあるので、自分で気をつけてください。
- **パスワードや合言葉はありません。** 作り直した後の版では、この道具に暗証番号を入れる場面はありません。

## 用意するもの

| 用意するもの | 説明 |
|---|---|
| パソコン | Windows でも Mac でもかまいません |
| Claude のアプリ | パソコンに入れて使う Claude の画面です。その中の「Cowork」という機能を使います |
| Claude のアカウント | Claude にログインするためのものです |
| Claude Docs | Claude の中で使える文書の機能です。論文の本文はここに書きます。使えるかどうかは契約の種類によって違う可能性があり、まだ確かめられていません |
| 授業のシラバス | AI をどこまで使ってよいかを確かめるためです |
| 学部の執筆要項(卒論のとき) | 字数や文字の大きさなど、書き方の決まりが書いてある資料です。PDF などのファイルで持っておくと便利です |

## 入れ方(最初に一度だけ)

Claude のアプリの Cowork で、次の順にクリックします。公式の説明書に書かれている手順です。この道具そのものでは、まだ試していません。

1. 画面の左側にある「Customize」を押す
2. 「Plugins」を押す
3. 「Add marketplace」を押し、出てきた入力欄に `imkoga002/student-plugins` と書いて決定する
4. 一覧に出てくる「ryukoku-writing」を選び、「Install」を押す

これで準備ができました。

## 論文用の場所を作る

論文ごとに、Cowork の「プロジェクト」を一つ作ります。プロジェクトは、一つの論文の作業をまとめておく入れ物です。

1. 左側の「Projects」を開き、「+」を押す
2. 「Start from scratch」(新しく始める)を選ぶ。パソコンに論文用のフォルダがすでにあれば、「Use an existing folder」でそのフォルダを選ぶ

## はじめかた

プロジェクトを開き、チャットの欄に次のように書いて送ります。

> 卒論を始めたい

AI が、論文の題(仮でかまいません)と、日本語で書くか英語で書くかを聞いてきます。答えると、AI が論文用の文書を Claude Docs に作り、画面に開きます。

## 文書の見かた

文書には、七つのタブ(紙のファイルの見出しのようなもの)があります。タブを押すと、中身が切り替わります。

| タブ | 何が入るか | あなたがすること |
|---|---|---|
| 原稿 | 論文の本文 | 自分で書く。授業が許せば、AI の下書きを見て受け入れる |
| 主張カード | あなたの言いたいことのまとめ | 自分の考えと合っているか確かめる |
| 文献台帳 | 使う本や論文の一覧 | 本や論文を実際に読んで確かめる |
| 問いと思考の記録 | 研究の問いと、考えたことのメモ | 自分だけで書く(AI は書きません) |
| 検証 | AI の点検の結果 | 読んで、直すかどうか決める |
| 設定 | 授業の条件や、書き方の決まり | 授業の条件をコメントで書く |
| 開示と提出前 | AI を使ったことの書き方と、提出前の確認 | 最後に確認のコメントを書く |

## あなたがする操作は二つだけ

### 1. AI の提案を受け入れる(✓ を押す)

授業の条件が「限定」か「不明」のとき、AI が書いた文はすぐには本文に入らず、色の付いた「提案」として表示されます(主張カードと設定のタブでは、条件にかかわらずいつも提案になります)。提案の横に出る ✓ を押すと本文に入り、✕ を押すと消えます。AI が ✓ や ✕ を押そうとすると止まるので、決めるのはあなたです。

### 2. コメントで決める

大事なことを決めるときは、文書にコメントを付けます。コメントは、文書の横に付ける短いメモです。付けたい文字を選ぶと、コメントのボタンが出ます。

決めることと、書く言葉は次のとおりです。言葉は、このとおりに書いてください。

| 決めること | どのタブで | コメントに書く言葉の例 |
|---|---|---|
| 授業の AI の条件 | 設定 | `科目の条件: 限定`(続けて `根拠: シラバス第1回「調べものには使ってよい」` のように、どこに書いてあったか) |
| 入力が AI の学習に使われない設定にしたこと | 設定 | `オプトアウト: 済` |
| 主張カードが自分の考えと合っていること | 主張カード | `C001 を確認` |
| 本や論文を実際に読んで確かめたこと | 文献台帳 | `S001 VERIFIED p.12`(確かめたページを必ず書く) |
| 提出してよいこと | 開示と提出前 | `提出を確認` |

授業の条件は、次の四つから選びます。

| 書く言葉 | 意味 | AI がすること |
|---|---|---|
| 許可 | 文章を書くのに AI を使ってよい | 本文に直接書く(書いたところは記録される) |
| 限定 | 一部だけ使ってよい | 本文には提案としてだけ書く。一つずつ見て決められる |
| 不明 | まだ分からない | 「限定」と同じ。分かったら書き直す |
| 禁止 | 文章を書くのに AI を使ってはいけない | 本文には何も書かない。資料探しと点検だけ手伝う |

コメントを付けたら、チャットで「コメントした」と知らせてください。AI がコメントを読みに行き、決めたことが記録されます。AI がこれらの言葉をコメントに書こうとすると止まります。言い回しを変えて書けてしまっても、文書には AI のコメントとして区別されて残るので、決めたことにはなりません。

## 書き進める流れ

1. **考えを話す**: 「〜が気になっている」「〜ではないかと思う」と、まとまっていなくてもよいのでチャットに書きます。AI が質問しながら、主張カードにまとめます
2. **主張を確かめる**: 主張カードを読み、自分の考えと合っていれば `C001 を確認` とコメントします
3. **資料を探す**: 「この主張の根拠になる論文を探して」と頼みます。見つかった資料は文献台帳に入ります
4. **資料を読む**: 図書館やインターネットで資料を実際に読み、確かめたら `S001 VERIFIED p.12` とコメントします
5. **書く**: 自分で書くか、授業が許せば「はじめにの下書きを書いて」と頼みます
6. **点検してもらう**: 「この節を点検して」と頼みます。結果は検証タブに出ます
7. **書き方を整える**: 執筆要項のファイルを渡して「この要項どおりに整えて」と頼みます(準備中。下の表を見てください)
8. **提出の前**: 開示と提出前のタブを読み、チェックの欄を埋めてから `提出を確認` とコメントします

## 困ったとき

| こんなとき | どうするか |
|---|---|
| AI が「止めた」「書かない」と言う | 授業の条件や、守るための決まりに当たったためです。理由が書かれているので読んでください。分からなければ、その文をそのままチャットに貼って「これはどういう意味?」と聞いてください |
| コメントを付けたのに記録されない | 書いた言葉が表と違うか、別のタブに付けた可能性があります。表の言葉どおりに、決められたタブで付け直してください |
| 資料のページを書き忘れた | `S001 VERIFIED p.12` のように、ページを入れてもう一度コメントしてください。ページのないコメントは数えられません |
| Claude Docs が見当たらない | お使いの契約では使えない可能性があります。先生か、この道具の作者に相談してください |
| 先生に見てもらいたい | 文書の上にある「Share」から、先生を招待できる場合があります。できないときは、文書の名前を押して「Export」から Word のファイルにして渡してください |
